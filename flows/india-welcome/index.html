Why this shape
  • Four emails, not three. 41% of the India list has never bought. E3 exists to answer why a cotton kurti costs ₹1,800 before the code runs out.
  • WhatsApp carries the code. It is the channel India buys on. Email carries the merchandising, SMS carries the deadline.
  • Founder letter at day 2. Plain text, no design. The founders are the brand and it is the proven format for a second email.
  • Every claim is on the live site. Free shipping, 24–48 hr dispatch, 7-day exchange with pickup. No "free returns", the India return fee is ₹180.
Build notes · Klaviyo + Bitespeed
  • Klaviyo owns the trigger, the emails and the SMS. WA1 is built as a Bitespeed flow off the same popup phone submit, so it is not a Klaviyo step.
  • The site already applies 10% automatically on orders over ₹2,599. Confirm whether the welcome code stacks before E1 goes live.
  • Code name and 7-day expiry are placeholders. Set the code in Klaviyo and Shopify before build.
  • SMS branch is built but held until DLT sender registration and a working STOP are confirmed.
  • E3 product cards link to live PDPs. Re-check stock and price the day the flow goes live.
