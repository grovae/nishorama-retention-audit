Setup
  • Market: Global (row.nishorama.com)
  • Live window: From the moment the sale opens to everyone until Tue 27 Oct 00:00. Then all 4 flows go to Manual, so nothing about the sale sends after it ends.
  • Welcome trigger: Diwali sale popup. The popup adds to the main newsletter list with source = diwali-popup-2026; this flow filters on it, and the regular welcome excludes it.
  • Browse trigger: Viewed Product. Filters: no order and no checkout since starting the flow, not in this flow in the last 3 days.
  • Checkout trigger: Checkout Started. Filter: Placed Order zero times since starting the flow.
  • Post-purchase trigger: Placed Order. Filters: Placed Order zero times since starting the flow, no Cancelled or Refunded Order.
  • Offer: Up to 50% off only. No codes in any of these emails (codes are first and last day only, and those go out as campaigns).
  • Swap: Regular browse and checkout flows go to Manual for the sale window (they carry NISHO10, which breaks the no-mid-sale-codes rule). Regular post-purchase stays live; PP1 runs alongside it.
  • Rules: no em dashes, no emoji in email copy, $, no returns or exchange line anywhere, no Diwali-delivery promise.
Open with client
  1. What does the Diwali popup promise? This copy assumes no code (no mid-sale codes). If it promises one, W1 carries it.
  2. Final URL of the sale landing page.
  3. Does the sale open to everyone on Thu 22 or Fri 23 (after VIP early access)? Flows go live at the public open.
  4. Global sale dates and end time zone ("ends Monday 26 Oct" is in every email).
  5. Reply-to inbox for W2's "just reply" (global@nishorama.com?).
